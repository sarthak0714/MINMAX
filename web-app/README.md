# MINMAX Web App

> ⚠️ **DEPRECATION NOTICE**: This web application is being deprecated and will be discontinued in future releases. All development efforts are now focused on the mobile-only experience.

## Overview

The MINMAX web app was the original web-based interface for workout tracking and progress analytics. It provided similar functionality to the mobile app through a responsive web interface.

## Why Deprecated?

We've decided to focus exclusively on the mobile app for the following reasons:

1. **Better User Experience** - Native mobile apps provide superior performance and UX for gym environments
2. **Offline Capability** - Mobile apps work better offline, essential for gym settings with poor connectivity
3. **Platform-Specific Features** - Native features like haptic feedback, notifications, and camera integration
4. **Simplified Maintenance** - Focusing on one platform allows faster iteration and better quality
5. **User Preference** - 95%+ of our users prefer the mobile app experience

## Migration Path

If you're currently using the web app:

1. **Download the mobile app** from the App Store or Google Play
2. **Configure your backend URL** using the secret gesture (tap "Today" 5 times)
3. **Your data is preserved** - All workout data is stored in the backend and will sync automatically

## For Developers

If you need to reference the web app codebase:

- The web app was built with React, TypeScript, and Tailwind CSS
- It used the same backend API as the mobile app
- Components and logic can be ported to the mobile app if needed

## Timeline
